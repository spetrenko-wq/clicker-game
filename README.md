# Міні-гра “Збирач монет”

Цей проєкт є інтерактивною міні-грою, розробленою мовою JavaScript із використанням бібліотеки p5.js. 
Гравець керує персонажем за допомогою клавіш стрілок або WASD та збирає монети, які з'являються у випадкових місцях на ігровому полі. 
У грі реалізовано динамічного ворога-переслідувача, початкова швидкість якого становить 120 px/сек. 
За кожні 5 зібраних монет швидкість ворога зростає на 10 px/сек, що поступово підвищує складність ігрового процесу. 
При зборі кожної монети відтворюється короткий звуковий ефект, згенерований за допомогою Web Audio API. 
У разі зіткнення з ворогом гра завершується (Game Over) із можливістю швидкого перезапуску клавішею Space або R. 
У майбутньому планується додати систему збереження найкращого результату (HighScore) у LocalStorage, нові види бонусів та перешкоди.
